# Hudson Valley School Calendars 2026-2027

Public calendar feeds for 19 Hudson Valley school districts, published by
Stevens Real Estate (eXp Realty), New Paltz NY.

Live site: https://max-briskey.github.io/school-calendars/

- `index.html` — the page clients land on from the QR codes on the printed calendars
- `ics/<district>.ics` — a subscribable feed per district

Each printed calendar's QR code opens this page anchored to its own district,
for example `#wappingers`.

Dates are compiled from each district's own published 2026-2027 calendar.
To correct a date, edit the matching entry and regenerate the `.ics` file.
Anyone subscribed picks the change up automatically.
